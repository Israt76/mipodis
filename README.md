# MIPODIS

Official public website repository for **MIPODIS — Migration-Ready Industrial Predictive Operations & Decision Intelligence System**.

Published research: *MIPODIS: A Migration-Ready Operational Decision-Intelligence Framework for Safe Data-Source Transitions*, Journal of Computer Science and Technology Studies, 8(9), 80–93 (2026).

DOI: https://doi.org/10.32996/jcsts.2026.8.9.9

Public site: https://israt76.github.io/mipodis/

## Repository scope
This repository contains only the public website and public metadata. The private MIPODIS enterprise implementation, internal thresholds, source code, customer data, credentials, and secrets are not published here.
